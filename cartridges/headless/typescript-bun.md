# TypeScript and Bun

Read the repository's package scripts and neighboring TypeScript before selecting commands or dependencies. In a Bun project, use its `bun test` conventions and `bun:sqlite` where the project uses SQLite; do not substitute Node or Jest conventions for Bun. Follow the repository's types, imports, scripts and existing test layout rather than assuming dependencies or APIs.
