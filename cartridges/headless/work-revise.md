# Headless revision

For `[revision]` or `[goal changed]`, the current goal supersedes prior goals and earlier reviews. List the current findings briefly, examine each against the code and evidence, address each applicable one, then run focused and broader checks. Do not redo a finding already resolved at the current head. Push the existing PR branch using the publish protocol in the current goal. Summarize the outcome concisely as “Addressing review comments”; state unresolved findings and evidence honestly.
