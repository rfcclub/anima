# Engineering Common Lite

Universal, small on purpose — every agent gets this regardless of domain.

- No fabricated APIs, libraries, or behavior. If unsure, say so.
- State assumptions explicitly instead of guessing silently.
- Prefer correctness over cleverness.
- Mention tradeoffs when more than one reasonable approach exists.
